Color Formats Explained

  • HEX: Six-digit hexadecimal code (e.g., #6C5CE7). Most common in web development.
  • RGB: Red, Green, Blue values from 0-255 (e.g., rgb(108,92,231)). Used in CSS and image editing.
  • HSL: Hue (0-360), Saturation (0-100%), Lightness (0-100%). More intuitive for color manipulation.

Color Theory Basics

Understanding color theory helps designers create visually appealing and effective designs. The color wheel, developed by Sir Isaac Newton, organizes colors in a circle showing the relationships between primary, secondary, and tertiary colors.

Primary colors: Red, blue, yellow — cannot be created by mixing other colors.
Secondary colors: Green, orange, purple — created by mixing two primary colors.
Tertiary colors: Created by mixing a primary and adjacent secondary color.

HEX vs RGB vs HSL

HEX (hexadecimal) is the most common format for web colors. It uses six digits representing red, green, and blue values: #RRGGBB. Example: #6C5CE7 represents a purple color.

RGB (Red, Green, Blue) uses values from 0 to 255 for each channel. Example: rgb(108, 92, 231). This format is commonly used in CSS and image editing software.

HSL (Hue, Saturation, Lightness) describes colors more intuitively. Hue (0-360) defines the color, Saturation (0-100%) defines intensity, and Lightness (0-100%) defines brightness.

Color Palette Design Tips

  • Use complementary colors (opposite on the color wheel) for high-contrast designs
  • Use analogous colors (adjacent on the wheel) for harmonious, calming designs
  • Follow the 60-30-10 rule: 60% dominant, 30% secondary, 10% accent
  • Consider color accessibility — ensure sufficient contrast for readability
  • Test your palette in grayscale to verify it works without color
