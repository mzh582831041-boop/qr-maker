如何使用

  1. 上传视频：点击或拖拽视频文件到上传区域
  2. 提取音频：点击「提取音频」按钮，下载 WAV 格式音频文件
  3. 生成字幕：切换到「生成字幕」标签，点击「开始识别」，朗读内容将实时转为文字
  4. 下载：识别完成后可下载 SRT 字幕文件

隐私说明

所有处理均在您的浏览器本地完成。上传的视频文件不会被发送到任何服务器。您无需担心隐私泄露。

注意事项

语音识别功能使用浏览器内置 API，建议使用 Chrome 或 Edge 浏览器 以获得最佳效果。识别的准确度受音频质量、语速、口音等因素影响。
