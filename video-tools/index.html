如何使用

  1. 上传视频：点击或拖拽视频文件到上传区域
  2. 提取音频：点击「提取音频」按钮，下载 WAV 格式音频文件
  3. 生成字幕：点击「开始识别」→ 允许麦克风权限 → 播放视频声音 → 浏览器自动转录 → 完成后点击停止 → 下载 SRT

隐私说明

所有处理均在您的浏览器本地完成。视频文件不上传任何服务器。

注意事项

语音识别使用浏览器内置 API，建议用 Chrome 或 Edge。播放视频时确保麦克风能收声。
